# ORL Procedure

Responsive booking system for ORL procedures, backed by Supabase.

- Staff link: <https://bookprocedure.s.gy/>
- Production host: <https://nazmiadnan92.github.io/ORL-Procedure/>

- Phase 1: database schema, access controls and transactional booking APIs
- Phase 2: public Staff booking form and read-only Booking List for today
- Phase 3: protected Admin history with inline procedure, notes and status editing
- Phase 4: monthly Clinic and Ward statistics by subspecialty and procedure
- Phase 5: idempotent migration of the verified legacy Google Sheet history
- Phase 6: public production deployment through GitHub Pages

Development notes are in `phase1.md` through `phase6.md`.
